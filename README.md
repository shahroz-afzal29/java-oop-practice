# Java Object-Oriented Programming (OOP) Practice

A curated collection of clean, foundational Java programs demonstrating essential Object-Oriented Programming (OOP) principles, structured class design, and practical console implementations.

---

## 📂 Repository Contents

| File Name | Concept Demonstrated | Description |
| :--- | :--- | :--- |
| `UserGreeting.java` | Standard I/O | Reads user input with `java.util.Scanner` and handles input streams. |
| `AreaOverloading.java` | Method Overloading | Compile-time polymorphism using identical method names with differing signatures. |
| `ShapePolymorphism.java` | Method Overriding | Runtime polymorphism using base and derived classes (`Shape`, `Circle`, `Rectangle`). |
| `EmployeePostComposition.java` | Composition ("Has-A") | Demonstrates encapsulation and object delegation between `Employee` and `Post`. |
| `UniversityManagement.java` | Inheritance ("Is-A") | Multi-level hierarchy using `super()` constructor chaining across university roles. |
| `BankEncapsulation.java` | Encapsulation & Validation | Enforces data security and balance state constraints using private fields. |

---

## 🛠️ Setup & Execution

### Prerequisites
* Java Development Kit (JDK 17 or later recommended)
* Visual Studio Code with the **Extension Pack for Java**

### Running via Terminal
To compile and execute any program directly:

```bash
# Compile
javac EmployeePostComposition.java

# Run
java EmployeePostComposition
